# Public Research Traces

This dataset may contain only explicitly donated, redacted, human-approved interactions.

## Pipeline

consent -> preview -> rights assertion -> redaction -> quarantine -> review -> license -> versioned release.

## V1 release rule

Do not publish a public trace dataset merely to satisfy V1. The donation interface and governance may launch before enough safe data exists.

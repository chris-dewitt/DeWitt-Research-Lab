# Definition of Ready and Definition of Done

## Ready

An issue is ready when it has user/research value, requirement ID, owned paths, prerequisites, accepted architecture or ADR gate, data/license needs, security implications, non-goals, acceptance, and test commands.

## Done

- behavior implemented for defined scope;
- meaningful tests pass;
- schema/API/docs updated;
- security/privacy/data/license effects addressed;
- telemetry and error behavior included;
- migration/rollback included if state changes;
- accessible UI states included;
- PR evidence and handoff complete;
- reviewer accepts;
- no hidden TODO required for claimed feature.

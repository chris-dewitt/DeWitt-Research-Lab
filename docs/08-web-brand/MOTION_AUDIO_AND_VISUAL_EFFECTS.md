# Motion, Audio, and Atmospheric Effects

## Good motion

- execution node activates as real event arrives;
- evidence lines draw to a claim;
- document diff reveals changes;
- chart animates once when calculation completes;
- pane transition communicates focus;
- model wake shows progress.

## Limits

- no essential information only in animation;
- no continuous high-energy background movement;
- reduced-motion removes nonessential effects;
- avoid layout shift;
- pause when offscreen;
- performance budget.

## Audio

Optional subtle interface sounds may exist but are muted by default and globally disableable. Public site never autoplays music or voice. Voice Atticus begins only through explicit user action.

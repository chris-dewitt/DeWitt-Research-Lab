# Provenance and Source Register

Every collection receives a source record:

- source ID/name/publisher;
- official URI or acquisition method;
- content type and scope;
- terms/license and snapshot date;
- redistribution/training/derivative permissions;
- collection script/version;
- expected update cadence;
- timestamp semantics;
- quality risks;
- owner and review status.

If raw redistribution is not allowed, release metadata, source links, checksums, and reproducible download/transformation scripts where permitted.

No agent may add a production data source without source-register entry and rights classification.

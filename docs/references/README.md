# Reference and Assumption Management

Primary references support current implementation assumptions; repository specifications remain the product authority. Agents must not cite an old reference register entry as proof that a current cloud feature, model license, framework API, or standard still behaves the same. Revalidate, update the register, and document material changes.

Research/source provenance for Atlas, FedLens, datasets, and publications belongs in the data source register and release manifests, not only here.

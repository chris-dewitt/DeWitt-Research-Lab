# Controlled Documentation System

## IDs

`DRL-<DOMAIN>-<NNN>`; project documents may use `ATT`, `ATL`, `FED`, `BAL`, `EVA`, `WEB`, `GCP`, `SEC`, `DAT`, `MOD`, `OPS`, `OSS`, `RES`.

## Status

Draft, Review, Approved Foundation, Approved Policy, Public Release Candidate, Public Release, Superseded, Withdrawn.

## Quality checks

- unique ID and valid frontmatter;
- no broken relative links;
- approved docs have no untracked placeholders;
- canonical references exist;
- changelog/version when meaning changes;
- traceability to requirements;
- owner/review freshness;
- public docs contain no private content.

Project docs are deeper than the Bible for their scope but may not redefine laboratory-wide rules.

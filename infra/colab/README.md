# Colab Research Environments

Colab notebooks are for research, teaching, baseline evaluation, QLoRA experiments, quantization, and release demonstrations.

## Rules

- notebooks are numbered and reproducible;
- dependencies are explicit;
- random seeds are recorded;
- outputs are not the only copy of results;
- checkpoints are written to approved persistent storage;
- private data is not uploaded by default;
- every notebook has a command-line or job equivalent before stable release.

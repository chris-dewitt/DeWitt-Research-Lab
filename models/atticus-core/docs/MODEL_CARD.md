# Atticus Core Model Card Template

- Release identity, upstream base and digests, architecture, context, languages, templates, licenses, and artifacts.
- Intended uses and out-of-scope uses.
- Training mixture, rights, method, compute, configuration, checkpoints, and known failures.
- AtticusBench results by slice; capability retention; quantization/runtime; human review and red team.
- Deployment requirements and mandatory external safeguards.
- Measured compute, latency, memory, and cost where available.
- Limitations, revision/deprecation policy, governance, contact, and security reporting.

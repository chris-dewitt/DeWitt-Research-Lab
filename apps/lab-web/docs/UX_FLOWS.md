# Website User Flows

## New visitor

Home -> systems map -> project case study -> Atticus guided tour -> GitHub or research artifact.

## Contributor

Open Source -> good first issue -> architecture/spec -> local setup -> contribution guide -> issue claim.

## Student or teacher

Teaching -> guided notebook -> Atticus explanation -> reproducible exercise -> citation and further reading.

## Hiring manager

Home -> integrated demo -> system architecture -> evaluation and failures -> founder page -> résumé.

## Researcher

Research -> working paper -> dataset/model card -> code and benchmark -> reproducibility instructions.

## Anonymous Atticus

Consent and privacy summary -> bounded session -> quota indicator -> result and trace -> optional account or trace donation.

## Trace donation

Select trace -> preview -> redact -> rights confirmation -> submit -> quarantine receipt.

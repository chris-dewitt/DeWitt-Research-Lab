# Atticus Core Safety, Rights, and Release

The selected upstream model must allow the intended research, redistribution, and commercial use. Apache-2.0 is preferred but never assumed. All upstream license, attribution, patent, naming, acceptable-use, and derivative-distribution requirements are recorded before training.

Every data source receives a rights decision for internal research and a separate decision for public dataset or weight release. Public Atticus contains no private DRL traces, personal files, email, voice, credentials, employer data, or unknown-rights copied corpora. Synthetic records retain generator, prompt/configuration, validator, reviewer, and license provenance.

The release states that Atticus is a proposal model and requires external schema validation, identity, policy, sandboxing, approvals, auditing, and deterministic domain tools. Benchmark success is not marketed as universal safety.

# Public Trace Donation Quarantine

This path stores **release-safe manifests and de-identified, reviewed public research traces only**. Raw public interactions do not flow here automatically. Donation requires an explicit consent snapshot, quarantine, privacy/security/license review, automated secret/PII detection, human review according to risk, provenance, and release approval.

Private local traces, raw voice, files, emails, repositories, credentials, and personalized adapters never belong here. See `docs/04-data/TRACE_DONATION_POLICY.md`.

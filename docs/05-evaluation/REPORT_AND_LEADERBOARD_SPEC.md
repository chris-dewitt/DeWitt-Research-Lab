# Evaluation Report and Leaderboard Specification

## Report sections

- run identity, code/data/model versions;
- environment and hardware;
- primary decision and thresholds;
- category metrics with uncertainty;
- baseline comparison;
- critical findings;
- latency/cost/resources;
- error clusters and examples;
- human/judge calibration;
- limitations and contamination note;
- machine-readable appendix;
- artifact hashes.

## Leaderboard

Public leaderboard entries distinguish model-only and scaffolded tracks. Require reproducible submission metadata and mark independently verified runs. Do not imply scores across different benchmark versions are directly comparable.

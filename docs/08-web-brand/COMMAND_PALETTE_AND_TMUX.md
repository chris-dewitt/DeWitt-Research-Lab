# Command Palette and Tmux Workspace Interaction

## Command classes

- navigate;
- search docs/research;
- open project/system;
- ask Atticus;
- start tour/replay;
- compare artifacts;
- toggle pane/layout;
- copy citation/install command;
- open issue/repository;
- accessibility/help.

## Tmux metaphor

Use pane titles, status bar, focus border, and layouts. Do not reproduce terminal limitations. Mouse, touch, keyboard, and screen-reader paths are equivalent.

Desktop layouts:

- reading: document + outline;
- research: sources + synthesis + Atticus;
- systems: architecture + trace + metrics;
- compare: baseline + candidate + diff;
- teaching: lesson + interactive example.

Mobile uses stacked tabs and bottom sheet rather than tiny panes.

# Laboratory System Console and Public Status

## Public console

- current release manifests;
- service live/replay/degraded status;
- public data freshness;
- model identity and availability;
- recent evaluation summaries;
- actual document/model/dataset/package counts;
- planned maintenance/incidents;
- link to detailed status page.

## Accuracy

Metrics come from generated public-safe manifests or APIs. If data is delayed, show timestamp. Operational/security internals remain restricted.

## Private operator console

Adds queue, budgets, errors, traces, deployments, feature flags, source ingestion, evaluation drift, and device status under strong authorization.

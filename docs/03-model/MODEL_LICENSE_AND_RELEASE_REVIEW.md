# Model License and Release Review

Before using or releasing a model:

- record exact upstream repository and revision;
- store license text and terms snapshot;
- identify restrictions, acceptable-use terms, attribution, notices, patent provisions, and redistribution rules;
- verify whether adapters, merged weights, quantizations, tokenizer, and generated synthetic data may be released;
- document dependencies and runtime licenses;
- review use of names and trademarks;
- create `NOTICE` and model-card attribution;
- obtain formal advice for ambiguity.

“Apache-2.0 code samples” on documentation does not establish the license of model weights. Weight terms are reviewed separately.

The release manifest lists original DRL artifacts, derivative artifacts, third-party artifacts, and applicable terms.

# Architecture Decision Records

Use ADRs for major decisions.

Number sequentially. Never delete an accepted ADR. Supersede it with a later ADR.

Required sections:

- Context
- Decision
- Alternatives
- Consequences
- Security and privacy
- Migration
- Approval

# ADR-0003: Plan Atticus Core and Edge from inception

## Decision

The platform supports an approximately 8B Core model and approximately 3B Edge model.

## Consequences

Protocols and datasets serve both sizes. V1 must release both, but benchmark-driven upstream selection remains open.

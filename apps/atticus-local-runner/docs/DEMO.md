    # Atticus Local Runner Demonstration and Portfolio Specification

    ## Purpose

    The demonstration proves the most important engineering claims of Atticus Local Runner. Every visible result is live, replayed from a signed real trace, cached from a dated artifact, or clearly marked illustrative.

    ## Signature story

    The Director asks Atticus by voice to inspect a synthetic repository, identify failing tests, prepare a patch, and explain it. Read-only work proceeds under local policy. The patch appears in a trusted approval view. Apply, commit, and push remain distinct decisions. The audit shows exactly what left the device.

    ## Modes

    - Recorded public technical walkthrough over a synthetic repository.
- Private owner-controlled live demo.
- Offline local-model demo.
- Security replay of a rejected malicious task.

    ## Guided sequence

    - Show paired device, version, and capability scopes.
- Issue a voice request and view the concise plan.
- Inspect repository read-only.
- Run tests in sandbox.
- Review patch and transfer summary.
- Approve or deny apply and optional commit; do not auto-push.
- Inspect local and cloud audit.
- Revoke device or switch offline.

    ## Safety and boundedness

    - Synthetic repo with no secrets.
- Public site uses replay, never live owner pairing.
- Directory, network, and action scopes are visible.
- Trusted local approval and kill switch.
- Screen recording is redacted.

    ## Measurements shown

    - Local and cloud steps.
- Policy and approval outcomes.
- Command profiles and test result.
- Files read or changed.
- Bytes transferred.
- Model route and latency.
- Audit digest without private content.

    ## Failure and fallback

    - Offline mode states unavailable specialists honestly.
- Sandbox failure leaves no partial untracked modification.
- Expired or denied approval leaves patch unapplied.
- Cloud failure can fall back only to declared offline features.

    The demo remains keyboard-operable, useful on mobile, compatible with reduced motion, and understandable without sound. A short visual loop, 90-second tour, and technical walkthrough all derive from the same truthful evidence.

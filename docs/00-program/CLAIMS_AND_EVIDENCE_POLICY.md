# Public Claims and Evidence Policy

DRL makes measurable claims only when the underlying evidence is available and appropriately qualified.

## Claim classes

- **Descriptive:** architecture, intended scope, supported interface.
- **Measured:** benchmark score, latency, cost, coverage, corpus size.
- **Comparative:** candidate versus baseline or alternative.
- **Causal/research:** an intervention produced an effect.
- **Maturity:** prototype, alpha, beta, stable, production-ready.

## Rules

- Measured claims identify environment, dataset version, sample size, date, and methodology.
- Comparative claims use the same task set and comparable conditions.
- Causal claims require a design capable of supporting causality; otherwise use association language.
- “Open source” specifies license and artifact availability.
- “Local” states which components can run locally and on what tested profile.
- “Secure” is replaced by specific controls and test results.
- “Production-ready” is prohibited before the operational release criteria are met.
- Website counters come from APIs or generated release manifests; no fabricated numbers.

Maintain a claim registry linking page copy to evidence artifacts. If evidence expires or becomes invalid, hide or qualify the claim.

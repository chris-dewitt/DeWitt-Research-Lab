# Dataset Release, Versioning, and Withdrawal

## Release contents

- dataset files or download/build scripts;
- manifest and checksums;
- schema;
- source/right register;
- transformation code;
- split method;
- quality and review report;
- contamination report;
- data card;
- changelog;
- known limitations;
- citation and license.

## Versioning

- patch: metadata or non-semantic correction;
- minor: additive records/fields without changing intended benchmark meaning;
- major: split, label, schema, or methodology change affecting comparisons.

Benchmarks pin exact versions. Withdrawn releases retain a tombstone explaining reason without continuing distribution where inappropriate.
